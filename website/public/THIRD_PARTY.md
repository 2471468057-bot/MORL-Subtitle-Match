# 第三方组件、字体与品牌

React / React DOM 19.2.8：MIT，原文随包位于 `licenses/react/LICENSE.txt`、`licenses/react-dom/LICENSE.txt`。

字体：页面内嵌的 “2B Sans” 是按本页用字裁剪的子集，均为 SIL Open Font License 1.1 授权，许可证原文见 `licenses/fonts/SourceHanSans-OFL-1.1.txt`。

- Medium、Heavy 两种字重来自思源黑体 Source Han Sans SC（Adobe，与桌面版随包字体相同）。
- 正文 Regular 字重来自 Noto Sans SC 可变字体（同一 Adobe 设计）在 400 字重处的实例。
- 按许可证对保留字体名 “Source” 的要求，子集已改名为 “2B Sans”，不单独出售或分发。

模型与厂商品牌图来自项目已有素材，权利属于各权利人。本演示没有重画这些标志，也不表示获得厂商背书。

2ByteASR 项目许可证保持原状；桌面模型、依赖和发布材料的既有审核边界不因网页交付而改变。
