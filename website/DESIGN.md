# 设计说明（2026-10-09）

**方向**：沉稳、清楚、耐看的产品宣传页，不是教学页，也不是互动假软件。先让人知道能省下什么、和一般自动字幕差在哪，再逐个展示核心能力。

- **底色**：全程深色，纯色加一层静态颗粒，章节之间只用两级底色和细线区分。不用装饰性渐变、渐变文字和光晕（用户 2026-10-09 反馈“明显的 AI 味”）；`npm test` 会检查构建后的样式里没有渐变。
- **颜色**：品牌莓果色 `#b34470` 只给主按钮和选中。每一区用桌面主题里已有的一种颜色做小标题与图标：优先审核 紫 `#a48ad9`、词库校对 杏 `#d6957c`、术语库 灰青 `#8aa5b8`、字级分轨 莓果 `#ec8db0`、导出 藕紫 `#c48cb4`、本地运行 天蓝 `#93bbe4`。绿、黄、橙、蓝只表示状态。
- **字体**：与桌面相同的思源黑体。标题 Heavy，界面文字 Medium，正文段落 Regular；数字和时间码用等宽字体。
- **版式**：版心最宽 1520px。每节同一节奏：左边大标题（关键短语用本节颜色）和说明，右边 3 个要点，下面一张全宽演示；五个演示同一尺寸。首屏标题在上，下面是全宽的主页 + 字幕工作台 3D 叠层，随鼠标倾斜。能力总览用“前后对比”表达，不用卡片网格。
- **动效**：段落进入时淡入上移 16 px。首屏叠层随鼠标倾斜约 ±7°（缓动跟随，减少动态效果或触屏时静止）。演示是时间驱动的短循环：进入画面才播放，鼠标停住暂停，点一下交给访客。
- **素材**：媒体画面统一用压暗的“无信号”测试卡占位，不用卡通插画，也不用真实游戏或赛事转播画面。

## 英文页与日文页（2026-10-09）

- 三种语言同一套版式、颜色、演示与尺寸，只换文字；不为某个语言另做设计。
- **英文**：字体沿用思源黑体（其拉丁字母即 Source Sans 的设计）。开启 `pwid`，让引号、撇号用拉丁宽度，不用中文全角宽度。首屏标题比中文长，标题栏放宽到 1.4 : 1，字号上限 80px，保证两行。
- **日文**：用读者系统里的日文字体，不嵌入。软件自带的思源黑体是简体中文版，汉字会显示成中文字形；系统里能找到的 Yu Gothic 许可不允许做网页字体。拉丁字母、数字和引号仍用页面字体，日文标题不加负字距（`palt` 已收紧假名）。等宽字体的后备也换成日文字体，避免日文落到 MS Gothic。
- **示例内容**：示例字幕、词条、术语都用本页语言显示（用户 2026-10-09 要求）；分句与时间与中文示例相同。听错的写法按该语言改写成同类错误（英文 Alana → Alanna、twelve F → 12F；日文 アラナ → アランナ、じゅうにエフ → 12F），游戏角色名用官方英文 / 日文名。页脚说明软件识别的是中文语音。
- **界面复刻**：按钮、标签用桌面程序该语言的界面文字；译文太长放不下时（如工具栏的“说话人管理 · 待确认”），改用更短的说法，并在 `ui.js` 注明。

## 参考的审美规则（2026-10-09）

来源：Leonxlnx/taste-skill（taste-skill、redesign-skill）与 h3nryprod01/design-taste（anti-slop 清单）。本页采用：不用同尺寸图标卡片网格；不在每节加小标签或编号；用字重和颜色拉开层次，关键短语加粗变白；正文行宽受限；页面宽度用足、全页统一节奏；不用破折号和成串的点分隔符；动效有目的、可关闭。
