# 2ByteASR：インストール、モデル、応用

## インストールと準備

1. [リリースページ](https://github.com/NOTBAD314/2ByteASR/releases)からインストーラーを選び、Setup を実行します。
2. モデル工房を開き、選んだモデルの重みをダウンロードして実行環境を準備します。
3. オンラインサービスを利用する場合は、対応するアカウント情報または API キーを入力します。
4. 動画や音声を読み込み、認識設定を選んで字幕の生成を開始します。

既定のテーマはディープグレープです。外観設定から配色を変更できます。

## モデルの選び方

メインの文字起こし、文字・単語のタイミング、テキストの照合には、それぞれ異なる役割があります。言語、機器、利用できるサービスに合わせて組み合わせられます。

| 役割 | 用途 | 主な選択肢 |
| --- | --- | --- |
| メインの文字起こし | 音声をテキスト化し、対応モデルでは話者も識別 | MOSS、SenseVoice、Whisper |
| 文字・単語のタイミング | 文字や単語の境界を捉え、分割とタイミング調整を補助 | FireRedASR2-AED、Paraformer、独立したアライナー |
| テキストの照合 | 候補を比べ、誤認識、固有名詞、文脈を確認 | Qwen3-ASR、ローカル／オンラインの照合モデル |

各モデルの動作要件はモデル工房で確認できます。SenseVoice は CPU に対応。MOSS、FireRedASR2-AED、Qwen3-ASR 1.7B、Qwen3-ForcedAligner は NVIDIA CUDA を使用します。モデルのダウンロード後は、ローカル認識をオフラインで実行できます。

AI による文の分割、テキスト校正、用語検索、字幕デザイン、クリップ分析は、必要に応じて利用できます。オンラインサービスには自分のアカウントまたは API キーを使用し、各サービスの規定に従って課金されます。処理対象の素材やテキストは、選択したサービスに送信されます。

## 入力と出力

| 用途 | 形式 |
| --- | --- |
| 動画の入力 | MP4、MOV、MKV、WebM、FLV、AVI |
| 音声の入力 | MP3、WAV、M4A、FLAC、AAC |
| Studio への字幕読み込み | SRT、ASS |
| 字幕・原稿の出力 | SRT、ASS、TXT、JSON、話者別トラック |
| 動画の出力 | MP4、MKV、MOV |

Studio で字幕とクリップを選択し、テキスト、時間、スタイル、映像を調整してから、必要な形式で書き出します。プロジェクトを保存すれば、次回も編集の続きを進められます。

## ソースからの実行とビルド

Windows のリポジトリディレクトリで、環境を準備して起動します。

```powershell
.\setup_environment.bat
.\.venv-main\Scripts\python.exe quick_start.py
```

開発とテストは[貢献ガイド](../CONTRIBUTING.md)、インストーラーの作成は[ビルド手順](../RELEASING.md)、設定項目は[設定ドキュメント](../CONFIGURATION.md)を参照してください。
