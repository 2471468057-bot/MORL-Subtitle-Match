# 兔白字幕 2ByteASR 0.6.5（Windows x64）

## 下载哪一个

**只需要下载 `2ByteASR-Setup-0.6.5.exe`（约 962 MB），运行它即可。** 安装后程序约 1.9 GB。其他附件是给程序内更新、校验和需要源码的人用的，一般使用者不用下载。

第一次使用还要按你选的识别组合下载运行环境和模型（首次设置画面会列出大小），不会默认把全部模型都下载：

| 识别组合 | 第一次使用另需下载（本次实测） |
| --- | --- |
| 高质量（MOSS 说话人 + FireRed 字级时间 + Qwen3-ASR 复核，需 NVIDIA 显卡） | 约 17.3 GB：模型 11.4 GB（MOSS 1.8、FireRed 4.7、Qwen3-ASR 4.7、说话人 0.09）＋运行环境约 5.9 GB（两份 PyTorch CUDA 各 2.6 GiB 等） |
| 轻量（SenseVoice） | 约 3.8 GB：模型 0.94 GB＋运行环境约 2.9 GB（PyTorch CUDA 2.6 GiB 等）。此组数字取自 0.6.0 安装后的同一套下载器实测 |
| 在线 API | 不下载本地模型，需自己的 API Key |

下载器支持断点续传与换源（ModelScope → HF 镜像 → HF 官方）；某个来源中断时已下载部分会保留，重试即可继续。

## 已经装过旧版本

- **0.6.0 及更早**：这些版本没有新的更新程序。关闭兔白字幕，下载 0.6.5 Setup **直接覆盖安装，不要先卸载**。设置、词库、工程、已下载的模型和运行环境都会保留：实测从 0.6.0 覆盖升级，只下载 Setup 本身（约 962 MB），模型与运行环境 0 字节重新下载，升级后直接识别成功。
- **0.6.5 起**：主界面右上角“检查更新”。只下载内容有变化的程序部分，下载前列出实际大小（只改程序代码时主程序包约 31 MB）；模型和运行环境沿用。下载后校验，等你保存工程并同意退出后才替换，失败会自动恢复原版本。

## 本版变化（相对 0.6.0 内部安装包）

- **程序内更新**：新的更新清单（Ed25519 签名）＋只下载变化部分＋独立更新程序（先备份、失败回退、新版启动失败也回退）。识别、导出、模型下载进行中不允许开始更新；未保存工程先提示保存。自动检查每天最多一次，不影响启动，没网也照常使用。
- **全新安装可用性修复**：模型工坊下载完 MOSS 或 Qwen3-ASR 后，“就绪检查”误报“模型加载失败”（检查程序没跟上 MOSS 整段识别的输出格式和 Qwen 的调用参数；0.6.0 同样有此问题）。现在两者下载完即可通过检查。
- **AI 词库校对页**：改字、采用建议、右键批量替换、Ctrl+H 都立即写进工程，可一步撤销；校对后能从结果页打开字幕工作台；搜索结果可拖选文字后右键批量替换；一字差异只标一个字；同一个技能名里的几处建议并成一组。
- **AI 文字校对**：修复整批超时；每批之间不再等待本机准备。
- **Studio 剃刀与合并**：剃刀按 FireRed 字级时间切分，预览画在字幕块内、不遮波形；合并工具改为轨道内预览；时间轴字幕文字居中。
- **启动与界面**：Studio、模型工坊、识别记录改为第一次进入时才建，启动明显变快；首页、设置、结果页、校对页可 Ctrl+滚轮缩放。

## 系统需求

- Windows 10 22H2（19045）或更新，64 位。
- 本地高质量组合（MOSS / FireRed / Qwen3-ASR）需要支持 CUDA 的 NVIDIA 显卡；没有时可用轻量组合或在线 API。
- 磁盘：程序约 2 GB，另加所选环境与模型（高质量组合实测见上表）。

## 已知限制

- **没有 Windows 代码签名证书**：Windows 可能显示“未知发布者”或 SmartScreen 提示。请只从本仓库 Releases 下载并核对 `SHA256SUMS.txt`；不需要也不应该关闭杀毒软件。更新清单另有发布者签名（Ed25519，key id `21f1cb35659cfffd`），SHA-256 只用于检查下载完整。
- 只提供 Windows x64。macOS 版本本轮没有构建与测试，不提供。
- AI 词库校对、AI 断句、在线识别等需要你自己的服务商 API Key；本轮没有用付费 API 做发布验收。
- 随附的 Remotion 4.0.513 与 GSAP 3.15.0 仍按各自许可使用：Remotion 免费许可只给个人、3 人以内公司等，其他组织需要 Remotion Company License；GSAP 不得用于与 Webflow 可视化动画构建竞争的无代码工具。随附 FFmpeg 里的 AAC 编码器是 fdk-aac-free（仅 LC-AAC）。第三方材料与仍未提供的确切构建材料见 `licenses/GPL3_ROUTE.md`、`licenses/SOURCES.md`。

## 源码与校验

- 自有代码：GPL-3.0-only（`LICENSE`），另有作者对 Remotion/GSAP 组合的 GPL 第 7 节附加许可（`PROJECT_LICENSE.md`）；附加许可只针对作者自有代码，不代表 Remotion 或 GSAP 的授权。
- `2ByteASR-Source-0.6.5.zip`：与本 Setup 对应的完整构建输入（源码、构建与安装脚本、锁文件、预编译构建输入）；不含不参与构建的 `website/` 与 `tests/`。`2ByteASR-ThirdParty-Materials-0.6.5.zip`：许可证与第三方声明；`2ByteASR-0.5.0-ThirdParty-Sources.zip`：自 0.5.0 起未变的第三方固定上游源码包（Qt/PySide 6.9.2、FFmpeg、mpv、Remotion Rust helper 等，本版仍使用相同版本）。
- `2ByteASR-update.json(.sig)` 与 `2ByteASR-0.6.5-<元件>-<哈希>.zip`：程序内更新使用的签名清单和元件包，不需要手动下载。
- 构建来源：发布提交 `a74c6d645858fa5cbacc80fda7c213f74267a198`。0.6.5 r9 实际是从开发提交 `c8c53456` 加未提交改动构建的；该发布提交是事后按构建快照整理的公开源码，干净检出逐字节重现构建源码指纹 `88dd50773fcad681c6bf2c73c28a53aa6749b4424c40019165bad3d48f66fbfb`（1199 个输入），`Source` 与 `ThirdParty-Materials` 两个附件合起来也重现同一指纹。

三种校验各管一件事，不能互相代替：

| 校验 | 证明什么 | 怎么核对 |
| --- | --- | --- |
| SHA-256（`SHA256SUMS.txt`） | 下载的文件完整、没被改坏 | `certutil -hashfile 2ByteASR-Setup-0.6.5.exe SHA256`，与清单中的值比对 |
| Ed25519 发布者签名（`SHA256SUMS.txt.sig`、`2ByteASR-update.json.sig`） | 校验和清单与更新清单确实由本项目发布者签发 | 见下方命令；程序内更新自动核对更新清单签名 |
| Windows 代码签名（Authenticode） | Windows 认可的发布者身份 | **本版没有**，Windows 可能提示“未知发布者”；不要因此关闭杀毒软件 |

`SHA256SUMS.txt.sig` 是发布者对 `SHA256SUMS.txt` 原始字节的 Ed25519 签名，与更新清单是同一把密钥：key id `21f1cb35659cfffd`，公钥 `idoW/Krfikfe7JY22oXVK3BOJQuXW+Lo7yNbas/oozc=`，也内置在 `twobyteasr/update_manifest.py`。在源码目录装好 `cryptography` 后运行：`python -c "from pathlib import Path; from twobyteasr.update_manifest import verify_manifest_signature as v; print(v(Path('SHA256SUMS.txt').read_bytes(), Path('SHA256SUMS.txt.sig').read_bytes()))"`。输出 key id 即签名有效，文件被改过则报错。
