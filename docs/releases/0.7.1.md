# 兔白字幕 2ByteASR 0.7.1（Windows x64・macOS Apple Silicon 实验版）

## 下载哪一个

| 你的电脑 | 下载 | 说明 |
| --- | --- | --- |
| **Windows 10 22H2 及以上（64 位）** | `2ByteASR-Setup-0.7.1.exe`（约 981 MB） | 运行它即可安装。已装 0.6.5／0.7.0 的用户也可以用程序内“检查更新”。 |
| **Mac：Apple 芯片（M 系列）、macOS 15 及以上** | `2ByteASR-0.7.1-macos-arm64-Setup.dmg`（约 0.5 GB） | **实验版**，只在 GitHub 的虚拟 Mac 上验证过。没有 Apple 公证：第一次打开请在 Finder 里按住 Control 点按 App →“打开”，不需要关闭系统安全设置。**不支持 Intel Mac。** |

其他附件是给程序内更新、校验和需要源码的人用的，一般用户不用下载。第一次本地识别仍会按你选的识别组合下载运行环境和模型，不会一次全部下载；只用云端识别则不需要下载模型。

## 这一版能做什么（相对 0.7.0）

### 新增功能

- **没有 NVIDIA 显卡也能出字幕。** 云端识别不再需要本地运行环境、PyTorch 或 CUDA。新增 MOSS Pro 云端（MOSI，含说话人）与阿里云百炼／Qwen Cloud 录音文件识别（Qwen3-ASR 给字词时间、Qwen-Audio-3.1 加说话人）。开始前会列出用哪个引擎、时间从哪里来、音频上传到哪里、大概费用；服务商只返回句段时间时，字幕标为“估算”，不冒充实测。录音文件识别的正式路线是上传到你自己的 OSS 私有空间、取回结果后删除；服务商的临时上传只在你选“仅供试用”时才用。
- **“申请与设置 API”。** 每家服务商一排图文步骤，按钮直接打开官方页面；填好后可分级测试，失败时说清楚是余额、Key、地域、模型还是网络的问题。
- **Mac 版（Apple 芯片，实验性）。** 云端识别；模型工坊能准备 MOSS（文字＋说话人）与 FireRedASR2-AED（字级时间），在这台 Mac 的 Apple GPU 上用内置样本实际跑一次，通过才启用；另有社区实现的 MLX 本地方案。工作台编辑、保存、重新打开、导出字幕与视频都可用。
- **新手引导。** 第一次启动先选识别方式（本地／云端／轻量）；首页按你电脑的实际状态提示下一步，附一个不需要任何模型的范例工程；31 步带动画的教学，可以在框内自己操作，也可以点“帮我做”。已经在用的用户不会被强制重走教学，双击工程照样直接进入工作台。
- **繁體中文界面。**
- **英文字幕。** 识别语言可选英语，输出可选英中双语；英文按单词断行（不切断单词、每行不超过 42 个字符），单词时间由 Qwen3-ForcedAligner 实测。
- **字幕标点**：保留原文／添加标点／不加标点，预览、工作台画面与所有导出一致，文稿本身不变。
- **快捷键**：所有页面的快捷键在设置里一处修改，冲突时会说出是哪个功能；在输入框里打字不会触发。
- **匹配文稿。** 已有断好句的完整文稿（每行一条字幕）时，工作台可直接用工程已有的字级时间对齐，先预览每句时间与匹配率、可一步撤销；首页也能只跑 FireRedASR2-AED 字级时间（目前只支持中文）。
- **识别方案**新增“日语推荐”“英语推荐”；日语 CTC 对齐模型可以自己选择使用或取消。
- **外部 AI（MCP）**：可按说话人与时间搜索；批量替换、标点先预览，经你在程序里批准才套用；只导出到你授权的文件夹；可一键写入 Claude Desktop 配置并显示是否真的连上。

### 使用体验与性能

- **中国大陆下载更稳。** 模型的自动来源依次是 ModelScope（固定版本）→ Hugging Face 官方 → hf-mirror.com（第三方，最后才用），每个文件都要和锁定的 SHA-256 一致；运行环境（uv、Python、PyTorch、PyPI 包）在官方源不通或太慢时改用国内镜像，同样逐个文件校验。下载窗口显示整个模型的进度、当前来源、换源原因、断点续传与校验结果。
- **MOSS 长直播不再显存不足**：放不下时按显存与上下文在静音处分段识别，再用声纹把说话人接起来。
- 新安装时，模型默认下载到程序所在文件夹的 `models`（程序装在 D 盘，模型也在 D 盘）；已下载的模型原地沿用、不搬。
- 文字复核真的会运行；云端复核开始前说明会上传什么、如何计费。
- 界面细节：被截断的文字、拥挤的播放按钮、相机按钮分隔线、“标点”与“压制成片”按钮样式、表格表头多一层框等。

### 问题修复

- 没装 FireRed（例如没有 NVIDIA）时，选 Qwen3 对齐却被错误跳过、字幕没有字级时间。
- 非日语任务的 Qwen 对齐时间轴从不运行。
- 没有父窗口的对话框与下拉框被回收时闪退（0xC0000374 一类）。
- “申请与设置 API”与在线识别对话框标题栏的 × 看不到。
- 打开工程时音频端点短暂断线，被直接判成“准备音频”失败。
- 教学结束后，范例工程留在“最近工程”。

- **0.6.0 及更早**：关闭兔白字幕，运行 0.7.1 Setup **直接覆盖安装，不要先卸载**。
- **Mac**：第一次提供，直接安装。

## 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases 下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **Mac 是实验版**：只在 GitHub 虚拟 Mac（虚拟 M1、7 GB 内存）上验证过，实体 Mac 与 8 GB 内存的 Mac 没测；没开文字复核时识别状态显示“部分降级成功”（每条字幕只有一个来源，文字与字时间正常）；窗口很窄时工作台顶部工具栏会重叠；Mac 的国内备用下载来源只在离线测试里验证过。
- **付费服务**：百炼录音文件识别已用真实 Key 验证；MOSS Pro 云端（MOSI）与 Qwen Cloud 没有用真实付费调用验证（只用本机模拟服务器跑过完整流程）。AI 校对、断句、翻译需要你自己的服务商 API Key。
- **中国大陆下载**只在一条家庭宽带线路上实测过（Windows）；其他运营商、校园网、手机热点没测。
- 首页“匹配文稿”目前只支持中文（工作台可用于日语／英语）。
- 4× 播放偶发整个窗口停住的原因仍未找到。
- **第三方许可**：Windows 随附的 gyan FFmpeg 9.0 仍缺构建脚本、可能的补丁与部分链接库的确切版本（gyan 没有公开这些材料）；x265 已核对完整，但这只代表 x265。Mac 的 FFmpeg／mpv 来自固定版本的 Homebrew 官方构建（配方与上游源码地址公开），本项目没有另附这些上游源码包。详见 `licenses/DISTRIBUTION-STATUS.md` 的 0.7.1 节。
