## 下載哪一個

| 你的電腦 | 下載 | 說明 |
| --- | --- | --- |
| **Windows 10 22H2 以上（64 位元）** | `2ByteASR-Setup-0.7.1.exe`（約 981 MB） | 執行它即可安裝。已裝 0.6.5／0.7.0 的人可以改用程式內「檢查更新」。 |
| **Mac：Apple 晶片（M 系列）、macOS 15 以上** | `2ByteASR-0.7.1-macos-arm64-Setup.dmg`（約 0.5 GB） | **實驗版**，只在 GitHub 的虛擬 Mac 上驗證過。沒有 Apple 公證：第一次開啟請在 Finder 按住 Control 點按 App →「打開」，不需要關閉系統安全設定。**不支援 Intel Mac。** |

## 這一版能做什麼（相對 0.7.0）

### 新增功能

- **沒有 NVIDIA 顯示卡也能出字幕。** 雲端辨識不再需要本機執行環境、PyTorch 或 CUDA。新增 MOSS Pro 雲端（MOSI，含說話人）與阿里雲百煉／Qwen Cloud 錄音檔辨識（Qwen3-ASR 給字詞時間、Qwen-Audio-3.1 加說話人）。開始前會列出用哪個引擎、時間從哪裡來、音訊上傳到哪裡、大概費用；服務商只回句段時間時，字幕標為「估算」，不冒充實測。錄音檔辨識的正式路線是上傳到你自己的 OSS 私有空間、取回結果後刪除；服務商的暫存上傳只在你選「僅供試用」時才用。
- **「申請與設定 API」。** 每家服務商一排圖文步驟，按鈕直接開官方頁面；填好後可分級測試，失敗時說清楚是餘額、Key、地域、模型還是網路的問題。
- **Mac 版（Apple 晶片，實驗性）。** 雲端辨識；模型工坊能準備 MOSS（文字＋說話人）與 FireRedASR2-AED（字級時間），在這台 Mac 的 Apple GPU 上用內建樣本實跑一次，通過才啟用；另有社群實作的 MLX 本機方案。工作台編輯、儲存、重開、匯出字幕與影片都可用。
- **新手引導。** 第一次啟動先選辨識方式（本機／雲端／輕量）；首頁按你電腦的實際狀態提示下一步，附一個不需要任何模型的範例工程；31 步帶動畫的教學，可以在框內自己操作，也可以按「幫我做」。已經在用的人不會被強制重跑教學，雙擊工程照樣直接進工作台。
- **繁體中文介面**（臺灣用詞，與簡體分開）。
- **英文字幕。** 辨識語言可選英語，輸出可選英中雙語；英文按單字斷行（不切斷單字、每行不超過 42 字元），單字時間由 Qwen3-ForcedAligner 實測。
- **字幕標點**：保留原文／添加標點／不加標點，預覽、工作台畫面與所有匯出一致，文稿本身不變。
- **快捷鍵**：所有頁面的快捷鍵在設定裡一處修改，衝突時會說出是哪個功能；在輸入框打字不會觸發。
- **匹配文稿。** 已有斷好句的完整文稿（每行一條字幕）時，工作台可直接用工程已有的字級時間對齊，先預覽每句時間與匹配率、可一步復原；首頁也能只跑 FireRedASR2-AED 字級時間（目前只支援中文）。
- **辨識方案**新增「日語推薦」「英語推薦」；日語 CTC 對齊模型可自己選擇使用或取消。
- **外部 AI（MCP）**：可按說話人與時間搜尋；批次替換、標點先預覽，經你在程式裡批准才套用；只匯出到你授權的資料夾；可一鍵寫入 Claude Desktop 設定並顯示是否真的連上。

### 使用體驗與效能

- **中國大陸下載更穩。** 模型的自動來源依序是 ModelScope（固定版本）→ Hugging Face 官方 → hf-mirror.com（第三方，最後才用），每個檔案都要和鎖定的 SHA-256 一致；執行環境（uv、Python、PyTorch、PyPI 套件）在官方來源不通或太慢時改用國內鏡像，同樣逐檔校驗。下載視窗顯示整個模型的進度、目前來源、換源原因、斷點續傳與校驗結果。
- **MOSS 長直播不再顯存不足**：放不下時按顯存與上下文在靜音處分段辨識，再用聲紋把說話人接起來。
- 新安裝時，模型預設下載到程式所在資料夾的 `models`（程式裝在 D 槽，模型也在 D 槽）；已下載的模型原地沿用、不搬。
- 文字複核真的會執行；雲端複核開始前說明會上傳什麼、如何計費。
- 介面細節：被截斷的文字、擁擠的播放按鈕、相機按鈕分隔線、「標點」與「壓制成片」按鈕樣式、表格表頭多一層框等。

### 問題修正

- 沒裝 FireRed（例如沒有 NVIDIA）時，選 Qwen3 對齊卻被錯誤跳過、字幕沒有字級時間。
- 非日語任務的 Qwen 對齊時間軸從不執行。
- 沒有父視窗的對話框與下拉框被回收時閃退（0xC0000374 一類）。
- 「申請與設定 API」與線上辨識對話框標題列的 × 看不到。
- 開啟工程時音訊端點短暫斷線，被直接判成「準備音訊」失敗。
- 教學結束後，範例工程留在「最近工程」。

## 已知限制

- **沒有程式碼簽章。** Windows 可能顯示「未知的發行者」；Mac 沒有 Apple 公證。請只從本倉庫 Releases 下載並核對 `SHA256SUMS.txt`；不需要、也不應該關閉防毒或系統安全設定。
- **Mac 是實驗版**：只在 GitHub 虛擬 Mac（虛擬 M1、7 GB 記憶體）上驗證過，實體 Mac 與 8 GB 記憶體的 Mac 沒測；沒開文字複核時辨識狀態顯示「部分降級成功」（每條字幕只有一個來源，文字與字時間正常）；視窗很窄時工作台頂部工具列會重疊；Mac 的國內備用下載來源只在離線測試驗證過。
- **付費服務**：百煉錄音檔辨識已用真實 Key 驗證；MOSS Pro 雲端（MOSI）與 Qwen Cloud 沒有用真實付費呼叫驗證（只用本機模擬伺服器跑過完整流程）。AI 校對、斷句、翻譯需要你自己的服務商 API Key。
- **中國大陸下載**只在一條家用寬頻線路上實測過（Windows）；其他電信商、校園網、手機熱點沒測。
- 首頁「匹配文稿」目前只支援中文（工作台可用於日語／英語）。
- 4× 播放偶發整窗停住的原因仍未找到。
- **第三方授權**：Windows 隨附的 gyan FFmpeg 9.0 仍缺建置腳本、可能的補丁與部分連結函式庫的確切版本（gyan 沒有公開這些材料）；x265 已核對完整，但這只代表 x265。Mac 的 FFmpeg／mpv 來自固定版本的 Homebrew 官方建置（配方與上游原始碼位址公開），本專案沒有另附這些上游原始碼包。詳見 `licenses/DISTRIBUTION-STATUS.md` 的 0.7.1 節。
