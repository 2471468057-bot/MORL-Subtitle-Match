### 这一版的变化（相对 0.7.1）

#### 新增

- **字幕翻译可以选目标语言。** 原文是中文、日语或英语时，译文可选简体中文、繁體中文、英语、日语、韩语中与原文不同的任一种；中文直播可以直接做英语或韩语字幕、双语字幕。翻译用你自己的文字 AI 服务。字幕字体缺少韩文或日文假名时，译文那一行自动改用程序自带的思源黑体，不会显示成方块。
- **韩语界面（한국어）。** 在首页右上角的语言选单（或第一次启动的窗口）切换。
- **15 套界面主题。** 外观页按浅色／深色／高对比分组，点卡片即时预览。

#### 问题修复

- **MOSS Pro 云端（MOSI）**
  - 素材在中文名称的文件夹里时报 `Invalid \escape`，识别失败。
  - 1 小时左右的录播上传约 15 秒就断开。
  - 上传途中断线后，完成页“重试失败项”一直被拒、也不询问。现在：文件确实没传完的会直接重新上传；无法确认服务商是否已经受理时，会先询问你再重新提交（可能再次计费）。
- **对白覆盖选“主播优先”**、又没有第二套识别（例如只用云端、没运行 FireRed）时，其他说话人的字幕被全部去掉。现在会保留，并列为“其他说话人未核对”的待复核项。
- AI 校对／断句的批次被拆分后又退回本机处理时，整个任务在最后一步失败（`invalid literal for int() … '2.1.2'`）。
- **工作台审核模式**：“重听”会一直播到下一条，时间轴停在下一条。现在只播当前这条（1× 与 2× 都是），播放中选中的条目不跳走；切换审核条目时画面不再上下跳动。
- **主窗口**（自绘标题栏）在多显示器下最大化后可能跑出屏幕、按钮够不到。现在会自动回到屏幕内；任务栏图标可以最小化／还原，Win+↑／↓ 可用；单击标题栏不会把最大化的窗口还原。
- 失败提示框的详情很长时在框内滚动，不再撑满整个屏幕。

### 已经装过旧版本

- **0.7.1、0.7.0、0.6.5**：主界面右上角“检查更新”。只下载有变化的部分（从 0.7.1 约 50 MB：程序；从 0.7.0 约 80 MB：程序与许可材料；从 0.6.5 约 462 MB：另加 Python 运行环境与渲染器），下载后校验，等你保存工程并同意退出后才替换；失败会自动恢复原版本。设置、词库、工程、已下载的模型与运行环境都保留。
- **0.6.0 及更早**：关闭兔白字幕，运行 0.7.2 Setup **直接覆盖安装，不要先卸载**。
- **Mac**：还没有程序内更新。退出旧版，打开新的 DMG，把 App 拖进“应用程序”替换即可；设置、模型和工程存放在 App 以外的用户资料夹（替换安装这一步本轮没有在 Mac 上实测）。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases 下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。

### What changed (compared with 0.7.1)

#### New

- **Subtitle translation lets you choose the target language.** When the original is Chinese, Japanese or English, the translation can be any of Simplified Chinese, Traditional Chinese, English, Japanese and Korean other than the original language; Chinese streams can go straight to English or Korean subtitles, or to bilingual subtitles. Translation uses your own text AI service. If the subtitle font lacks Korean characters or Japanese kana, the translated line automatically switches to the bundled Source Han Sans, so it is not shown as boxes.
- **Korean interface (한국어).** Switch to it from the language menu at the top right of the home screen (or in the window shown at first launch).
- **15 interface themes.** The Appearance page groups them into Light, Dark and High contrast; click a card for an instant preview.

#### Fixed

- **MOSS Pro cloud (MOSI)**
  - When the media was in a folder with a Chinese name, recognition failed with `Invalid \escape`.
  - Uploads of stream recordings around 1 hour long disconnected after about 15 seconds.
  - After the connection dropped during an upload, "Retry failed tasks" on the completion page was rejected every time, without asking. Now, if the file really did not finish uploading, it is uploaded again directly; if the app cannot confirm whether the provider has already accepted it, it asks you before resubmitting (you may be charged again).
- **With dialogue coverage set to "Streamer first"** and no second recognition pass (for example, cloud only, without running FireRed), all subtitles from other speakers were removed. They are now kept and listed as an item to review, noting that the other speakers were not cross-checked.
- When an AI proofreading or segmentation batch was split and then fell back to local processing, the whole task failed at the last step (`invalid literal for int() … '2.1.2'`).
- **Studio review mode**: "Replay" kept playing into the next line, and the timeline stopped on the next line. Now it plays only the current line (at both 1× and 2×), the selected line does not jump away during playback, and the view no longer jumps up and down when you switch review items.
- **Main window** (custom-drawn title bar): on multiple monitors, it could end up off-screen after being maximized, with its buttons out of reach. It now moves back onto the screen automatically; the taskbar icon can minimize and restore it, Win+↑/↓ work, and a single click on the title bar no longer restores a maximized window.
- Long details in failure dialogs now scroll inside the dialog instead of filling the whole screen.

### Updating from an earlier version

- **0.7.1, 0.7.0, 0.6.5**: "Check for updates" at the top right of the main window. Only the changed parts are downloaded (from 0.7.1 about 50 MB: the program; from 0.7.0 about 80 MB: the program and licence materials; from 0.6.5 about 462 MB: also the Python runtime and the renderer). They are verified after downloading and replace the old files only after you save your project and agree to quit; if anything fails, the previous version is restored automatically. Settings, glossaries, projects, downloaded models and runtimes are all kept.
- **0.6.0 and earlier**: close 2ByteASR and run the 0.7.2 Setup **to install over the old version. Do not uninstall first.**
- **Mac**: there is no in-app update yet. Quit the old version, open the new DMG and drag the app into "Applications" to replace the old one; settings, models and projects are stored in a user folder outside the app (this replacement step was not tested on a Mac in this round).

### 달라진 점(0.7.1 대비)

#### 새 기능

- **자막 번역에서 대상 언어를 고를 수 있습니다.** 원문이 중국어, 일본어, 영어일 때 번역문은 중국어 간체, 중국어 번체, 영어, 일본어, 한국어 가운데 원문과 다른 언어를 고를 수 있습니다. 중국어 방송으로 영어나 한국어 자막, 이중 언어 자막을 바로 만들 수 있습니다. 번역에는 본인의 텍스트 AI 서비스를 사용합니다. 자막 글꼴에 한글이나 일본어 가나가 없으면 번역문 줄은 앱에 포함된 본고딕(Source Han Sans)으로 자동 전환되어 네모로 표시되지 않습니다.
- **한국어 인터페이스(한국어).** 홈 화면 오른쪽 위의 언어 메뉴(또는 처음 실행할 때 나오는 창)에서 바꿀 수 있습니다.
- **15가지 UI 테마.** “모양” 페이지에서 라이트/다크/고대비로 나뉘어 있으며, 카드를 클릭하면 바로 미리 볼 수 있습니다.

#### 수정된 문제

- **MOSS Pro 클라우드(MOSI)**
  - 미디어 파일이 중국어 이름의 폴더에 있으면 `Invalid \escape` 오류가 나며 인식에 실패했습니다.
  - 1시간 안팎의 방송 녹화본을 업로드하면 약 15초 만에 연결이 끊겼습니다.
  - 업로드 도중 연결이 끊긴 뒤 완료 화면의 “실패한 작업 다시 시도”가 묻지도 않고 계속 거부되었습니다. 이제 파일 업로드가 실제로 끝나지 않았으면 바로 다시 업로드합니다. 서비스 업체가 이미 접수했는지 확인할 수 없으면 다시 제출하기 전에 먼저 묻습니다(요금이 다시 청구될 수 있습니다).
- **대사 범위를 “스트리머 우선”으로 설정**하고 두 번째 인식이 없을 때(예: 클라우드만 쓰고 FireRed를 실행하지 않은 경우) 다른 화자의 자막이 모두 삭제되었습니다. 이제는 삭제하지 않고 남겨 두며, 다른 화자를 대조하지 않았다는 검토 항목으로 표시합니다.
- AI 교정/줄 나누기 배치가 나뉜 뒤 로컬 처리로 되돌아가면 작업 전체가 마지막 단계에서 실패했습니다(`invalid literal for int() … '2.1.2'`).
- **자막 스튜디오 검토 모드**: “다시 듣기”가 다음 줄까지 계속 재생되어 타임라인이 다음 줄에서 멈췄습니다. 이제 현재 줄만 재생하며(1×와 2× 모두), 재생 중에 선택한 줄이 다른 줄로 넘어가지 않습니다. 검토 항목을 바꿀 때 화면이 위아래로 튀지 않습니다.
- **메인 창**(직접 그린 제목 표시줄): 여러 모니터 환경에서 최대화한 뒤 창이 화면 밖으로 나가 버튼을 누를 수 없게 되는 경우가 있었습니다. 이제 자동으로 화면 안으로 돌아옵니다. 작업 표시줄 아이콘으로 최소화/복원할 수 있고, Win+↑/↓도 작동하며, 제목 표시줄을 한 번 클릭해도 최대화된 창이 복원되지 않습니다.
- 실패 안내 창의 상세 내용이 길면 창 안에서 스크롤되며, 더 이상 화면 전체를 채우지 않습니다.

### 이전 버전에서 업데이트하기

- **0.7.1, 0.7.0, 0.6.5**: 메인 화면 오른쪽 위의 “업데이트 확인”을 사용합니다. 바뀐 부분만 내려받으며(0.7.1에서는 약 50 MB: 프로그램, 0.7.0에서는 약 80 MB: 프로그램과 라이선스 자료, 0.6.5에서는 약 462 MB: 여기에 Python 실행 환경과 렌더러 추가), 내려받은 뒤 검증하고, 프로젝트를 저장하고 종료에 동의한 다음에 교체합니다. 실패하면 자동으로 원래 버전으로 되돌립니다. 설정, 용어 라이브러리, 프로젝트, 내려받은 모델과 실행 환경은 모두 유지됩니다.
- **0.6.0 이하**: 2ByteASR를 종료하고 0.7.2 Setup을 실행해 **그대로 덮어 설치합니다. 먼저 제거하지 마십시오.**
- **Mac**: 아직 앱 내 업데이트가 없습니다. 이전 버전을 종료하고 새 DMG를 연 뒤 앱을 “응용 프로그램” 폴더로 끌어다 놓아 교체하면 됩니다. 설정, 모델, 프로젝트는 앱 바깥의 사용자 자료 폴더에 저장됩니다(이 교체 설치 단계는 이번에 Mac에서 직접 테스트하지 않았습니다).

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서는 “알 수 없는 게시자”가 표시될 수 있고, Mac 버전은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases에서만 내려받고 `SHA256SUMS.txt`로 확인하십시오. 백신 프로그램이나 시스템 보안 설정을 끌 필요가 없으며, 꺼서도 안 됩니다.
- **Mac 버전은 실험판입니다**: GitHub 가상 Mac에서만 확인했고, 실제 Mac과 메모리 8 GB Mac은 테스트하지 않았습니다. 창이 아주 좁으면 자막 스튜디오 위쪽 도구 막대가 겹칩니다.
- **한국어 인터페이스는 새로 추가되었습니다**: 일부 용어가 어색할 수 있습니다. 영어, 일본어, 한국어 인터페이스에는 아직 중국어로 표시되는 문구가 조금 남아 있습니다.
- **유료 서비스**: 이번 MOSS Pro 클라우드 수정 사항은 개발자가 평소 쓰는 버전에서 실제 계정으로 1시간 방송 녹화본을 인식해 확인했습니다(클라우드 코드는 동일). Qwen Cloud는 실제 유료 호출로 확인하지 않았습니다. AI 교정, 줄 나누기, 번역에는 본인의 서비스 업체 API Key가 필요합니다.
- 홈 화면의 “원고 맞추기”는 현재 중국어만 지원합니다(자막 스튜디오에서는 일본어/영어에도 쓸 수 있습니다).
- 4× 재생 중 가끔 창 전체가 멈추는 원인은 아직 찾지 못했습니다.
