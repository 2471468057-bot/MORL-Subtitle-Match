### 这一版的变化（相对 0.7.2）

#### 新增

- **不填 API Key 也能出字幕。** 以前开着 AI 校对／AI 断句却没填 Key，点「开始生成字幕」会弹“AI 配置未保存”，任务不开始。现在这次改用本地规则断句、不做 AI 校对，照常出字幕、能导出；不上传、不花钱。保存的开关不变，以后填上 Key 就自动用 AI。Key 填了但地址或模型写错时仍会提示。首页 AI 卡片没 Key 时写“不填也能用”。
- **「API Key 是什么？」图解。** 四段动画：不填也能出字幕、API Key 是一把钥匙、先充值（10 元就够先用）、复制贴进兔白。首页 AI 卡片、AI 设置、首次选择窗口、「申请与设置 API」和「说明」菜单都能打开；「申请与设置 API」的步骤加上了充值一步。
- **新手教学改成看图跟着做。** 基础 10 步，每步一句话配动画，到导出为止；学完可以接着学进阶 20 步（改错字、审核、调时间、压制），「说明」菜单也能单独打开进阶。
- **审核时点一下改错字。** 审核模式第 1 张卡标出其他识别模型写得不一样的地方、词库里确认过的错写和他/她/它；点一下只改那一处，可撤销；按 **P** 整条切换他/她。
- **AI 校对按上下文改他/她/它**（识别时与 AI 词库校对页都适用）。
- **手改的名字自动记进词库。** 工程套用了词库时，把听错的写法记成正确名字的别名；撤销这次修改会一并删掉。
- **匹配文稿支持日语、英语。** 可选或自动判断中文／日语／英语；日语、英语用本机 Qwen3-ASR 与 Qwen3 对齐模型（需要这两个模型）。

#### 问题修复

- **Qwen3 对齐模型加载少占约 3 GB 虚拟内存。** 页面文件偏小、原来报“页面文件太小（os error 1455）”的电脑更容易通过；仍不够时模型工坊说明是虚拟内存不足并给出处理步骤；显存还有余却报 CUDA out of memory 时也不再说成“硬件无法执行此模型”。
- 压制完成页的成片预览按成片原分辨率截帧，明显变清楚。
- 新手教学换步时气泡和框不再抽动，框里的控件能直接点，离开页面会暂停成「回到教学」小条，工作台视频不再被盖黑。
- 首页「字幕时间轴」卡按字幕语言显示实际会运行的模型（日语：Qwen3 对齐 + 日语 CTC）。
- 任务报告与识别记录按实际情况写“本地规则断句”，不再把它显示成 AI 模型。

- **0.7.2、0.7.1、0.7.0、0.6.5**：主界面右上角“检查更新”。只下载有变化的部分（从 0.7.2／0.7.1 约 52 MB：程序；从 0.7.0 约 81 MB：程序与许可材料；从 0.6.5 约 464 MB：另加 Python 运行环境与渲染器），下载后校验，等你保存工程并同意退出后才替换；失败会自动恢复原版本。设置、词库、工程、已下载的模型与运行环境都保留。

### 已知限制

- **没有代码签名。** Windows 可能显示“未知发布者”；Mac 没有 Apple 公证。请只从本仓库 Releases 下载并核对 `SHA256SUMS.txt`；不需要、也不应该关闭杀毒软件或系统安全设置。
- **Mac 是实验版**：只在 GitHub 虚拟 Mac 上验证过，实体 Mac 与 8 GB 内存的 Mac 没测；窗口很窄时工作台顶部工具栏会重叠。
- **不填 Key 时**：这次用本地规则断句，句子比 AI 断句粗一些，也不做 AI 校对。工作台里自己点的 AI 功能（「AI 断句」菜单、AI 词库校对、翻译、AI 设计等）没 Key 时仍是原来的“缺少 API 密钥”报错，下一版改成先说明。
- “10 元就够先用”是建议，不是服务商承诺的额度。
- 英语、日语、韩语界面里仍有少数文字显示为中文。
- 4× 播放偶发整个窗口停住的原因仍未找到。
- **第三方许可**：Windows 随附的 gyan FFmpeg 9.0 仍缺构建脚本、可能的补丁与部分链接库的确切版本（gyan 没有公开这些材料）。Mac 的 FFmpeg／mpv 来自固定版本的 Homebrew 官方构建。详见 `licenses/DISTRIBUTION-STATUS.md`。

### What changed (compared with 0.7.2)

#### New

- **Subtitles without an API key.** Before, if AI proofreading or AI line splitting was on but no key was filled in, "Start" showed "AI settings not saved" and the job did not start. Now that run splits lines with local rules and skips AI proofreading, and still produces and exports subtitles; nothing is uploaded and nothing is charged. Your saved switches stay as they are, so AI is used automatically once you add a key. A key that is filled in but has a wrong address or model is still reported. Without a key, the AI card on the home screen says that it works without one.
- **"What is an API key?" picture guide.** Four short animations: subtitles work without a key; an API key is like a key to a door; top up first (about ¥10 is enough to start); copy it and paste it into 2ByteASR. It opens from the AI card on the home screen, AI settings, the first-run choice window, "Apply for and set up an API" and the Help menu; "Apply for and set up an API" now includes the top-up step.
- **The beginner tutorial is now picture-based.** 10 basic steps, one sentence and one animation each, up to exporting; then you can continue with 20 advanced steps (fixing words, review, timing, burning in), which can also be opened on their own from the Help menu.
- **Click once to fix a word during review.** The first card in review mode marks where other recognizers wrote something different, misspellings confirmed in the glossary, and he/she/it (他/她/它); one click changes only that spot and can be undone; press **P** to switch he/she for the whole line.
- **AI proofreading fixes he/she/it from context** (during recognition and on the AI glossary proofreading page).
- **Names you correct by hand are saved to the glossary.** When the project uses a glossary, the misheard spelling is recorded as an alias of the correct name; undoing the edit removes it again.
- **Match script supports Japanese and English.** Choose the language or let it detect Chinese/Japanese/English; Japanese and English use the local Qwen3-ASR and Qwen3 aligner models (both needed).

#### Fixed

- **The Qwen3 aligner uses about 3 GB less virtual memory while loading.** PCs with a small paging file that reported "The paging file is too small (os error 1455)" pass more easily; if memory is still not enough, the Model workshop says that virtual memory is too small and lists what to do, and "CUDA out of memory" with plenty of video memory left is no longer reported as "this hardware cannot run the model".
- The finished-video preview on the export completion page is captured at the video's own resolution and is much sharper.
- The beginner tutorial no longer jerks the bubble and frame between steps, controls inside the frame can be clicked directly, leaving the page pauses it into a small "Back to tutorial" bar, and the Studio video is no longer covered in black.
- The "Subtitle timeline" card on the home screen shows the models that will actually run for the subtitle language (Japanese: Qwen3 aligner + Japanese CTC).
- Task reports and the recognition history now say "local rules" for line splitting when that is what ran, instead of naming an AI model.

### Updating from an earlier version

- **0.7.2, 0.7.1, 0.7.0, 0.6.5**: "Check for updates" at the top right of the main window. Only the changed parts are downloaded (from 0.7.2/0.7.1 about 52 MB: the program; from 0.7.0 about 81 MB: the program and licence materials; from 0.6.5 about 464 MB: also the Python runtime and the renderer). They are verified after downloading and replace the old files only after you save your project and agree to quit; if anything fails, the previous version is restored automatically. Settings, glossaries, projects, downloaded models and runtimes are all kept.
- **0.6.0 and earlier**: close 2ByteASR and run the 0.7.3 Setup **to install over the old version. Do not uninstall first.**
- **Mac**: there is no in-app update yet. Quit the old version, open the new DMG and drag the app into "Applications" to replace the old one; settings, models and projects are stored in a user folder outside the app (this replacement step was not tested on a Mac in this round).

### 変更点（0.7.2 との比較）

#### 新機能

- **API キーを入れなくても字幕を作れます。** これまでは AI 校正／AI 文分割がオンのままキーが未入力だと、「開始」で「AI 設定が保存されていません」と表示され、タスクが始まりませんでした。現在は、その回だけローカルの規則で文を区切り、AI 校正は行わずに、字幕の作成と書き出しをそのまま行います。アップロードも課金もありません。保存したスイッチは変わらないので、あとでキーを入れれば自動的に AI を使います。キーは入っているがアドレスやモデルが間違っている場合は、これまでどおり知らせます。キーがないとき、ホーム画面の AI カードには「入力しなくても使えます」と表示されます。
- **「API キーとは？」の図解。** 4 つの短いアニメーション：キーなしでも字幕は作れる、API キーは鍵のようなもの、先にチャージ（約 10 元あれば始められます）、コピーして 2ByteASR に貼り付け。ホーム画面の AI カード、AI 設定、初回の選択ウィンドウ、「API の申請と設定」、「ヘルプ」メニューから開けます。「API の申請と設定」の手順にチャージの段階を加えました。
- **初心者チュートリアルを図で見ながら進める形にしました。** 基本 10 ステップ（1 ステップごとに 1 文とアニメーション、書き出しまで）。続けて応用 20 ステップ（誤字の修正、レビュー、タイミング調整、焼き込み）も学べ、「ヘルプ」メニューから応用だけを開くこともできます。
- **レビュー中にクリック 1 回で誤字を直せます。** レビューモードの 1 枚目のカードに、ほかの認識モデルと書き方が違う箇所、用語集で確認済みの誤記、他/她/它（彼/彼女/それ）を表示します。クリックするとその箇所だけを直し、元に戻せます。**P** キーで行全体の他/她を切り替えます。
- **AI 校正が文脈に合わせて他/她/它を直します**（認識時と AI 用語集校正ページの両方）。
- **手で直した名前を用語集に自動で記録します。** プロジェクトに用語集を適用しているとき、聞き間違えた書き方を正しい名前の別名として記録します。修正を元に戻すと記録も削除されます。
- **台本合わせが日本語・英語に対応しました。** 言語を選ぶか、中国語／日本語／英語を自動判定します。日本語と英語にはローカルの Qwen3-ASR と Qwen3 アライナーを使います（両方のモデルが必要です）。

#### 修正

- **Qwen3 アライナーの読み込み時の仮想メモリ使用量が約 3 GB 減りました。** ページング ファイルが小さく「ページング ファイルが小さすぎるため、この操作を完了できません（os error 1455）」と出ていた PC でも通りやすくなりました。それでも足りない場合、モデルワークショップは仮想メモリ不足であることと対処の手順を表示します。ビデオメモリに余裕があるのに CUDA out of memory が出た場合も、「このハードウェアではモデルを実行できません」とは表示しなくなりました。
- 書き出し完了ページの完成映像プレビューを、映像本来の解像度で切り出すようにし、くっきり見えるようになりました。
- 初心者チュートリアルで、ステップの切り替え時に吹き出しと枠がガタつかなくなり、枠の中のボタンを直接押せ、ページを離れると「チュートリアルに戻る」の小さなバーで一時停止し、字幕スタジオの映像が黒く覆われなくなりました。

### 달라진 점(0.7.2 대비)

#### 새 기능

- **API Key를 넣지 않아도 자막을 만들 수 있습니다.** 이전에는 AI 교정/AI 줄 나누기가 켜져 있는데 Key가 없으면 “시작”을 눌렀을 때 “AI 설정이 저장되지 않았습니다”가 뜨고 작업이 시작되지 않았습니다. 이제 그 작업은 로컬 규칙으로 줄을 나누고 AI 교정은 건너뛴 채 자막 생성과 내보내기를 그대로 진행합니다. 업로드도 요금도 없습니다. 저장된 스위치는 바뀌지 않으므로 나중에 Key를 넣으면 자동으로 AI를 씁니다. Key는 있지만 주소나 모델이 틀린 경우에는 지금처럼 알려 줍니다. Key가 없으면 홈 화면 AI 카드에 “넣지 않아도 쓸 수 있습니다”라고 표시됩니다.
- **“API Key란?” 그림 안내.** 짧은 애니메이션 네 개: Key 없이도 자막을 만들 수 있음, API Key는 열쇠와 같음, 먼저 충전(약 10위안이면 시작 가능), 복사해서 2ByteASR에 붙여 넣기. 홈 화면 AI 카드, AI 설정, 처음 실행 시 선택 창, “API 신청 및 설정”, “도움말” 메뉴에서 열 수 있으며, “API 신청 및 설정” 단계에 충전 단계를 추가했습니다.
- **초보자 튜토리얼이 그림을 보며 따라 하는 방식으로 바뀌었습니다.** 기본 10단계(단계마다 한 문장과 애니메이션, 내보내기까지). 이어서 고급 20단계(틀린 글자 고치기, 검토, 타이밍 조정, 자막 입히기)도 배울 수 있고, “도움말” 메뉴에서 고급만 따로 열 수도 있습니다.
- **검토 중 한 번 클릭으로 틀린 글자를 고칩니다.** 검토 모드의 첫 번째 카드에 다른 인식 모델과 다르게 쓴 곳, 용어집에서 확인된 오기, 他/她/它(그/그녀/그것)를 표시합니다. 클릭하면 그 부분만 고치고 되돌릴 수 있으며, **P** 키로 줄 전체의 他/她를 바꿉니다.
- **AI 교정이 문맥에 따라 他/她/它를 고칩니다**(인식할 때와 AI 용어집 교정 페이지 모두).
- **직접 고친 이름을 용어집에 자동으로 기록합니다.** 프로젝트에 용어집을 적용했을 때 잘못 들은 표기를 올바른 이름의 별칭으로 기록하며, 수정을 되돌리면 기록도 함께 지워집니다.
- **대본 맞추기가 일본어·영어를 지원합니다.** 언어를 고르거나 중국어/일본어/영어를 자동으로 판단합니다. 일본어와 영어에는 로컬 Qwen3-ASR과 Qwen3 정렬 모델을 씁니다(두 모델 모두 필요).

#### 수정된 문제

- **Qwen3 정렬 모델을 불러올 때 가상 메모리를 약 3 GB 덜 씁니다.** 페이징 파일이 작아 “페이징 파일이 너무 작습니다(os error 1455)”가 나던 PC에서도 더 잘 통과합니다. 그래도 부족하면 모델 워크숍이 가상 메모리 부족이라는 것과 해결 단계를 보여 주며, 비디오 메모리가 남아 있는데 CUDA out of memory가 나는 경우에도 더 이상 “이 하드웨어에서는 모델을 실행할 수 없습니다”라고 표시하지 않습니다.
- 내보내기 완료 페이지의 완성 영상 미리보기를 영상 원래 해상도로 캡처해 훨씬 선명해졌습니다.
- 초보자 튜토리얼에서 단계를 바꿀 때 말풍선과 테두리가 떨리지 않고, 테두리 안의 버튼을 바로 누를 수 있으며, 페이지를 벗어나면 “튜토리얼로 돌아가기” 작은 막대로 일시 정지하고, 자막 스튜디오 영상이 검게 가려지지 않습니다.
- 홈 화면의 “자막 타임라인” 카드에 자막 언어에 따라 실제로 실행될 모델을 표시합니다(일본어: Qwen3 정렬 + 일본어 CTC).
- 작업 보고서와 인식 기록에 실제로 로컬 규칙으로 줄을 나눈 경우 “로컬 규칙”이라고 적으며, AI 모델로 표시하지 않습니다.

### 알려진 제한

- **코드 서명이 없습니다.** Windows에서는 “알 수 없는 게시자”가 표시될 수 있고, Mac 버전은 Apple 공증을 받지 않았습니다. 이 저장소의 Releases에서만 내려받고 `SHA256SUMS.txt`로 확인하십시오. 백신 프로그램이나 시스템 보안 설정을 끌 필요가 없으며, 꺼서도 안 됩니다.
- **Mac 버전은 실험판입니다**: GitHub 가상 Mac에서만 확인했고, 실제 Mac과 메모리 8 GB Mac은 테스트하지 않았습니다. 창이 아주 좁으면 자막 스튜디오 위쪽 도구 막대가 겹칩니다.
- **Key가 없을 때**: 그 작업은 로컬 규칙으로 줄을 나누므로 AI 줄 나누기보다 거칠고, AI 교정도 하지 않습니다. 자막 스튜디오에서 직접 실행하는 AI 기능(“AI 줄 나누기” 메뉴, AI 용어집 교정, 번역, AI 디자인 등)은 Key가 없으면 지금처럼 “API Key가 없습니다” 오류가 납니다. 다음 버전에서 먼저 안내하도록 바꿉니다.
- “약 10위안이면 시작 가능”은 권장 금액이며, 서비스 업체가 약속한 금액이 아닙니다.
- 영어, 일본어, 한국어 인터페이스에는 아직 중국어로 표시되는 문구가 조금 남아 있습니다.
- 4× 재생 중 가끔 창 전체가 멈추는 원인은 아직 찾지 못했습니다.
