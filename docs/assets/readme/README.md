# README 素材说明

2026-10-14 更新：首页与界面一览改用 **0.7.1** 的真实截图和真实操作录制，示例画面从自绘小游戏换成克制的测试卡。

2026-10-15 补充：新增韩语界面素材（`*-ko.*`），截自 **0.7.2**（tag `v0.7.2`）的程序源码，做法与下面相同；`clips-ko.webp` 是同一段 HyperFrames 动画加入韩语文字后重新渲染。中文、英文、日文素材仍是 0.7.1 的截图。

## 读者需要知道的

- **截图和动图是真的**：全部来自 tag `v0.7.1` 的程序源码（与 0.7.1 安装包同一提交），在隔离的 Windows 私有桌面上启动正常主窗口截取。用户数据、缓存、工程都写在临时测试文件夹里，只读取本机已登记的运行环境和模型，并阻止对外网络连接。没有使用安装版 EXE 截图；界面代码与安装包相同，但截图用的 FFmpeg 等外部工具是开发机上的版本。
- **素材是自制的**：示例视频是测试卡画面（彩条、时间码和随语音变化的电平条），配合 Windows 自带中文语音合成的两人对话（男声 Kangkang、女声 Yaoyao）。没有使用游戏实录、直播录像、私人媒体、用户配置或密钥。
- **识别是真的跑过的**：34 秒示例在本机用 MOSS + FireRedASR2-AED + Qwen3-ASR 识别（NVIDIA RTX 5070 Ti，约 2 分 03 秒，含模型加载），关闭 AI 断句与 AI 校对。得到 14 条字幕，两位说话人分成两轨。“他／它”一处三个模型写法不同，是候选对照动图里采用 Qwen 写法的那一句；几处规则断句不当，是剃刀动图里合并再切开的那一句。
- **只做了这些处理**：裁切、缩放、圆角、在纯色背景上叠放两个窗口（主图）、调色板压缩与 WebP 编码；`export.png` 中本机输出路径用色块遮住。没有修改界面文字、按钮或识别结果。说话人名称“主播”“队友”（英文 Host／Teammate，日文 配信者／相方，韩文 스트리머／팀원）是在说话人管理里实际输入的。
- **不是基准**：耗时和结果只代表这一段示例，不说明模型速度或准确率。

## 录制时看到、尚未修复的界面问题

素材取景尽量避开它们，但没有修改画面：

- 英文界面即使在 1600 宽，字幕工作台标题栏的“Punctuation: Original kept”也会压住“Export subtitles”的图标；1440 宽时更明显。中文界面在 1320 宽时“标点：保留原文”也会压住“导出字幕”。
- 英文、日文、韩文界面仍有不少中文：术语库（试一下、改名、导出词库、全选可见行等）、说话人管理的部分按钮、审核候选的理由文字和“当前”标签。
- 日文界面的剃刀工具同时译作“レーザー”和“カッター”。
- 审核模式里采用候选后，暂停中的视频预览会只剩字幕选择框、不显示字幕文字，直到下一次刷新；所以候选动图只截候选条。
