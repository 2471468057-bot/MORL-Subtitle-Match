# 2ByteASR：画面と機能の紹介

素材の読み込みから字幕付き動画の完成まで、ひとつのワークフローで進められます。

![2ByteASR のホーム画面](assets/readme/overview.png)

## デスクトップのホーム画面

素材、用語集、認識設定をホーム画面でまとめて管理。半透明の字幕ワークスペース入口には、最新のプロジェクトのサムネイルが背景として表示され、前回の編集を続けられます。

![デスクトップアプリのホーム画面](assets/readme/desktop-brand.png)
