# 兔白字幕：界面一览

下面全部是软件真实界面（2026-10-09 开发版）。示例素材是项目自制的动画画面和合成双人语音，字幕由本机 MOSS + FireRedASR2-AED + Qwen3-ASR 识别。素材来源与制作方法见[素材说明](assets/readme/README.md)。

## 首页与识别

![首页：素材入口、三种识别角色、AI 智能断句与内容术语](assets/readme/home.png)

首页：拖入素材，选好主力转写、字幕时间轴和文字复核，再点“开始生成字幕”。

![识别进度：当前步骤、处理记录与完整运行日志](assets/readme/progress.png)

识别进度：当前步骤、每一步的用时与结果、完整运行日志。

![完成页：字幕条数、用时、待检查项与字幕预览](assets/readme/completion.png)

完成页：条数、用时、待检查项和全部字幕预览。

## 字幕工作台

![字幕工作台全貌](assets/readme/studio.png)

字幕列表、视频预览、样式面板和按说话人分轨的时间轴在同一个窗口里。

![剃刀切分：合并后拖动剃刀，预览前后两段再切开](assets/readme/razor.gif)

剃刀：按住拖动预览前后两段，松开切开，切点落在字词边界上。

![审核模式：对照三个模型的不同文字并采用](assets/readme/review.gif)

审核：并排列出不同模型的文字并标出差异，点选即采用。

![说话人管理：改名、颜色与默认样式](assets/readme/speakers.png)

说话人管理：改名、设颜色和默认样式。

## 术语、模型与主题

![游戏术语库](assets/readme/glossary.png)

游戏术语库：按游戏整理术语、错词、来源与确认状态。
